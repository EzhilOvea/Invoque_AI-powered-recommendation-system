This recommendation system uses python libraries and recommends movies based on user interests# AI-Powered Movie Recommendation System

This project uses Python libraries to recommend movies based on the user's selected movie and its similarities to other movies.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- NLTK

## Methodology
The system uses content-based filtering with CountVectorizer and cosine similarity to recommend similar movies.

## Dataset
TMDB 5000 Movie Dataset from Kaggle.

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
